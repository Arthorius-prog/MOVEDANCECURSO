# MoveDance — Site para curso de dança

Este projeto é um MVP/front-end responsivo para lançamento de um curso de dança.

## Já incluído
- Página de vendas
- Seção de benefícios
- Módulos de videoaulas
- Prévia de aula em modal
- Agenda de aulas ao vivo
- Agendamento salvo no navegador (localStorage)
- Pedido de permissão para notificações do navegador
- Área de matrícula/preço
- FAQ
- Layout responsivo para celular
- Botão de WhatsApp
- Estrutura pronta para integrar vídeos e pagamento

## Para colocar em produção
1. Substitua os vídeos de demonstração pelos seus vídeos.
2. Troque o valor e os textos da oferta.
3. Coloque seu número real no WhatsApp em `script.js`.
4. Conecte o botão de matrícula a um checkout (Mercado Pago, Stripe, Hotmart etc.).
5. Para login dos alunos, pagamentos, agenda compartilhada e notificações automáticas, será necessário um backend/banco de dados.
6. Publique os arquivos em uma hospedagem como Vercel, Netlify ou servidor próprio.
